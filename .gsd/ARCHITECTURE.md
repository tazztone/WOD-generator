## Data Flow

1. **Configuration:** `ConfigScreen` updates `appState.config` → `storage.js` persists to localStorage.
2. **Generation:** `App.jsx` calls `generateWorkout()` → `generator.js` filters `EXERCISE_DB` → returns workout object.
3. **Execution:** `ActiveTimer` tracks progress → `App.jsx` receives result → `saveToHistory` updates state and localStorage.
4. **Android Native:** `App.addListener('backButton')` intercepts hardware back press to navigate `appState` instead of closing the app.
