## Lessons Learned
- **Testing Action Labels**: Accessible names for buttons (like "Start Timer") are more reliable than partial matches when icons are involved. Using `data-testid` is even better for core flows.
- **Linting Early**: Syntax differences (like JSON import styles) should be checked against project ESLint rules early to avoid late-stage refactoring.
- **State Hygiene**: Explicit "clear" actions in Context are better than relying on component unmounting for clearing global state.
