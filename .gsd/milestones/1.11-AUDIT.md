## Concerns
- **Parsing/Linting**: The use of newer syntax (`import ... with { type: 'json' }`) caused initial linting failures. It's better to stick to established patterns in this project's setup.
- **Test Fragility**: `screen.getByRole` was fragile with SVG icons inside buttons; switched to `data-testid` for the "Start Timer" button.

## Recommendations
1. **Testing**: Always use `data-testid` for primary action buttons to avoid label/SVG fragility.
2. **Linting**: Run `npm run lint` more frequently during development to catch syntax compatibility issues early.
