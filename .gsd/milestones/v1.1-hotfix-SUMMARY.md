## Lessons Learned
- **Architecture Mapping**: Running `/map` on a brownfield project is essential to avoid using outdated or generalized package names (like `com.tazztone.wodgen`) that don't match the specific `applicationId` in the native code.
- **Testing Tracks**: New Google Play accounts have a 14-day 12-tester requirement. CI workflows should default to the `internal` track during this period to avoid production "precondition" errors.
